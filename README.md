# 💰 Expense Tracker Web Application

A simple, responsive, and user-friendly **Expense Tracker Web Application** developed using HTML, CSS, and JavaScript. It helps users manage their income and expenses, monitor their spending, and track their remaining balance.

## 🌐 Live Demo

[**Click here to view Expense Tracker**](https://symphonious-narwhal-242bdf.netlify.app/)

## ✨ Features

- **Add Transactions:** Add income and expense details.
- **Transaction History:** View all recorded transactions.
- **Delete Transactions:** Remove unwanted transactions.
- **Automatic Calculation:** Calculate total income, total expenses, and remaining balance.
- **Data Persistence:** Store transaction details using browser LocalStorage.
- **Responsive Design:** Simple and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive layout.
- **JavaScript** – Application functionality and calculations.
- **LocalStorage** – Saving transaction data in the browser.
- **Netlify** – Website deployment and hosting.

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/pushpabalabhadra/expense-tracker.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your transactions.
